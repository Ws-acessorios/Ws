Gestão segura no GitHub

Esta área funciona inteiramente no GitHub Pages. O token é enviado directamente do seu navegador para a API do GitHub, permanece apenas na memória desta página e nunca é guardado no navegador, no repositório ou no catálogo.

Crie um token de granularidade fina limitado ao repositório Ws-acessorios/Ws. São necessárias apenas as permissões Metadata: Read-only e Contents: Read and write.
PermissãoNívelFinalidade
MetadataRead-onlyConfirmar o repositório e a branch.
ContentsRead and writeLer, actualizar e criar ficheiros publicados.

Sessão GitHub validada.

Todas as publicações pedem confirmação e utilizam o SHA remoto actual. Se outro utilizador alterar o ficheiro, a Gestão interrompe a publicação para evitar sobrescritas silenciosas.
